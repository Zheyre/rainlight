# Rainlight

A 24/7 rain ambience with rotating affirmations for confidence, self-love, growth, and rest.

- `index.html` page structure
- `style.css` look and time of day color themes
- `script.js` rain animation, rain and thunder sound, affirmation rotation
- `affirmations/affirmations.json` all affirmations, grouped by time of day
- `assets/` future images, logo, and audio

Add `?stream=1` to the address for a clean version with no controls (used for the livestream).
Add `?period=morning` (or afternoon, evening, night) to preview a theme.
